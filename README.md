# JavaScript Fundamentals - Day 1

Daily tasks covering JavaScript basics, calculations and string utilities.

### 🚀 Live Demo
Live Link: https://your-live-link.netlify.app

### 📝 Tasks Covered

**1. Introduce Yourself**
- Created variables: name, age, city, isStudent, skill
- Printed introduction using template literals
- Checked typeof for each variable

**2. Shop Bill Calculator**
- 3 items price and quantity in variables
- Calculated subtotal, 5% discount, 17% GST and final total
- Printed clean bill using template literals

**3. Converters and String Utilities**
- Celsius to Fahrenheit converter: `F = C * 9 / 5 + 32`
- Email clean using `trim()` and `toLowerCase()`
- Validated email with `includes('@')` and `endsWith('.com')`
- Bonus: Took number from user with `prompt()` and calculated square using `Number()` conversion
